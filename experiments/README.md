# Experiments

This directory contains reproducible tests of future sufficiency, representation closure, and tightly bounded empirical instruments that inform the framework without inheriting theory authority automatically.

Current surfaces include:

- **Future-Sufficiency Arena** — synthetic/reproducible tests of representational closure and future-relevant distinctions.
- **CUHK-X empirical suite** — a real multimodal human-activity case study for measurement → representation → accessibility → exploitation → adoption under subject-held-out transfer. See [`cuhk_x/`](cuhk_x/). CUHK-X is treated as an FS instrument, not as a direct Future-Sufficiency benchmark.
