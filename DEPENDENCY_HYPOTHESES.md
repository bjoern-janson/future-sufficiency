## Candidate dependency: independent challengeability

Notation:

    E_challenge
        = an external or sufficiently independent evidence channel
          capable of exposing a discrepancy that the current hypothesis language
          cannot make visible from its ordinary evidence stream.

Candidate hypothesis:

> **Independent challengeability may be a necessary substrate for future-sufficient hypothesis repair.**

The motivation is an identifiability limit.

If:

    H* not in H_t

but every evidence channel available to the loop is itself generated, filtered, or interpreted through the same insufficient hypothesis language, then the states

    "the current language is adequate"

and

    "the current language is inadequate but the inadequacy is observationally invisible"

may be indistinguishable to the loop.

Formally, for two underlying worlds `W_A` and `W_B`, if the available evidence operator `O_H` satisfies:

    O_H(W_A) = O_H(W_B)

while:

    adequate(H_t, W_A) != adequate(H_t, W_B),

then no decision rule over `O_H` alone can reliably choose different meta-actions in the two worlds.

This would be an epistemic non-identifiability result, not a failure of optimization inside the loop.

## Constitutive versus empirical status

The challenge-channel hypothesis must not be declared necessary merely because the latest audit supplies one.

Two possibilities must remain live:

### Empirical necessity

Removing or degrading independent challengeability preserves the meaning of the repair contract, but selectively destroys one or more preregistered properties such as:

- hypothesis-language insufficiency detection;
- warranted reopening;
- correct rejection of false closure.

Then an intervention can earn an edge such as:

    E_challenge -> Q_reopen

or:

    E_challenge -> diagnosis(H_t insufficient).

### Constitutive limit

Removing all possible challenge information makes the target distinction itself unidentifiable:

    available evidence is identical
    while
    required meta-action differs.

In that case, independent challengeability is not merely an engineering dependency of a particular algorithm. Some evidence path capable of separating the relevant worlds is constitutive of the epistemic problem.

The research claim should then be about an impossibility boundary, not about a failed repair mechanism.

## Edge acquisition rule

Do not add `E_challenge` to the minimal causal core from the current audit alone.

A causal dependency edge requires:

    intervene on challengeability
    -> preregistered localized failure
    -> replication
    -> matched controls
    -> rule out incidental information / compute loss
    -> classify empirical necessity vs constitutive non-identifiability

In particular:

    supplied in a successful audit
    !=
    causally necessary.

## Current scientific question

The next high-level dependency question is:

> What evidence topology is minimally sufficient for a loop to detect that its own hypothesis language is inadequate?

This should be answered by dependency identification, not by adding another capability rung.

The high-value distinction is:

    internal cleverness
    !=
    epistemic access.

A system cannot repair a distinction that no admissible evidence path can make identifiable.

## Scientific rule

**Do not confuse absence of corrective evidence with failure to use corrective evidence.**

A missing challenge path is a candidate interface / identifiability failure, not automatically an inference failure.
